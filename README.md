## 📦 功能
* 具有uiaccess的置顶锁屏
* 密码解锁与USB密钥解锁
* 时间/倒计时/日期显示
* 正常时段与黑屏时段（适合午休），支持从Classisland导入课间时间
* 个性化主题/控件开关
* 与特点软件（如白板）的豁免条件及受控制的快捷启动
> [!IMPORTANT]
>
> 目前每次运行均会索要UAC授权，您可前往 用户账户控制 将等级调至最低，但请注意日后对需要管理员权限的不良程序防护

## 🚀 使用
1. 下载并解压
2. 双击运行start.bat
> [!TIP]
>
> 初始密码为114514
> 要想创建密钥，在u盘根目录创建与配置相同的文件名的文件即可，默认为 key.txt

## ❕提示
- 目前不适用于有键盘的一体机（没有屏蔽快捷键等）目前只有uiaccess提权
- 如果你授权uac后无法打开，请查看系统是否禁用了ti权限（需要将其开启）
- 打开设置耗费时间较长，请耐心等待
- 开机自启项在公共的启动文件夹
